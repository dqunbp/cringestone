# Cringestone

Объёмная карточная дуэль в браузере: гоблинский профсоюз против академии случайного волшебства. Русский интерфейс, два готовых набора по 30 карт, локальный бот, оригинальные иллюстрации и синтезированные звуковые эффекты.

## Запуск

Требуются Node.js 24 LTS и npm. Версия Node указана в `.nvmrc`, зависимости закреплены в `package-lock.json`.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Игра рассчитана на компьютер с мышью или трекпадом и WebGL2. Рекомендуемый размер окна — 1440×900 или больше, минимальная ширина — 1024 px. При сужении окна партия ставится на паузу и продолжается после расширения. Все ресурсы загружаются локально; API-ключи и внешние сервисы для игры не нужны.

```sh
npm run typecheck
npm run check:assets
npm test
npx playwright install chromium webkit
npm run test:e2e
npm run build
npm run preview
```

Производственная сборка находится в `dist`. Её нужно отдавать HTTP-сервером, а не открывать `index.html` через `file://`. Публикация в интернет в эту версию не входит.

## Управление

- Выберите героя, затем замените ненужные стартовые карты и подтвердите руку.
- Перетащите карту на свою сторону стола или на подходящую цель. Можно последовательно нажать на карту и место/цель.
- Для атаки протяните существо к врагу либо нажмите на атакующего и затем на цель.
- Escape отменяет выбор и перетаскивание. Доступные действия и цели подсвечены.
- «Карты и цели» открывает альтернативное управление через обычные кнопки.
- Способность героя стоит 2 маны и доступна один раз за ход. Кнопка «Завершить ход» передаёт ход боту.
- В меню доступны новая партия, выбор героя и звук. Настройка звука сохраняется локально. Партия живёт только в памяти вкладки.

Если сцена исчезает или зависает, откройте **Меню → Скачать диагностику**. Эта кнопка есть и на экране ошибки загрузки. JSON содержит последние 300 технических событий: загрузку ресурсов, скрытие сцены через Suspense, потерю WebGL-контекста, большие промежутки между кадрами и этапы хода. Журнал остаётся в этой вкладке, переживает её перезагрузку через `sessionStorage` и никуда автоматически не отправляется. Это диагностический отчёт, а не сохранение партии.

## Состав v1

20 уникальных карт (10 общих и по 5 фракционных), стажёр 1/1 и жетон дополнительной маны. В колоде две копии каждой доступной карты. Правила включают провокацию, боевые кличи, урон, лечение, усиление, добор, переполнение руки/поля, усталость, победу и ничью.

Начальные числовые характеристики точно соответствуют согласованному плану. Баланс стартовый: результаты игры ботов не следует считать показателем равной силы фракций для человека.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `src/core` | Чистые правила, каталог, seeded RNG, разрешённые команды и представление игрока |
| `src/bot` | Детерминированная эвристика на основе собственной руки и открытой информации |
| `src/presentation` | Локальная сессия, блокировка взаимодействий, очередность событий |
| `src/scene` | Three.js / React Three Fiber: стол, карты, жетоны, движение и эффекты |
| `src/ui`, `src/styles` | React DOM: меню, подсказки, интерфейс боя и результат |
| `src/audio` | Оригинальные эффекты Web Audio API |
| `public/assets` | Локальные иллюстрации и шрифты |
| `tests/core`, `tests/e2e` | Проверки правил, симуляции и браузерные сценарии |

Подробнее: [архитектура](docs/architecture.md), [ассеты и промпты](docs/assets/prompts.md), [проверка версии](docs/validation.md). Метаданные и SHA-256 всех 26 изображений находятся в `docs/assets/manifest.json`.

Стек: TypeScript strict, React 19, Three.js WebGL2, React Three Fiber 9, Drei 10, GSAP, Vite, Vitest и Playwright. Сервер, аккаунты, мультиплеер, редактор колод и пользовательские наборы карт отложены; ядро не зависит от браузера и может быть использовано будущей серверной сессией.
