# Проверка Cringestone v1

Дата: 23 октября 2026. Среда: macOS, Apple M4 Pro, Node.js 24. Проверки выполнены локально; игра не опубликована.

## Сборка и ресурсы

- `npm run typecheck` — успешно.
- `npm test` — 22 теста в двух файлах, успешно.
- `npm run check:assets` — все 26 PNG имеют корректный формат и разрешение не менее 512 px; шрифты и лицензии присутствуют.
- `npm run build` — успешно, артефакт `dist`.
- Исходные PNG занимают 67.6 MiB. Это локальная версия с оригиналами; оптимизация сетевой доставки изображений относится к подготовке публикации. Для 3D GPU-копии ограничены 512 px, полноразмерные файлы доступны DOM-просмотру.

## Ядро и бот

Покрыты расход маны, допустимые цели, провокация, задержка атаки, одновременный урон, массовый урон, усиление и лечение, ограничения поля/руки, сжигание карты, усталость, mulligan, способности, победа/ничья, неизменность исходного состояния при отказе, независимость представлений и воспроизводимость RNG.

100 воспроизводимых матчей бот против бота завершились без невалидных команд и зависаний. Прогон содержит 9806 команд; самый длинный матч — 40 ходов. Стартовая модель бота дала 87 побед академии и 13 профсоюзу. Это сигнал для будущей балансировки и улучшения эвристик, а не доказательство равного игрового баланса. Согласованные числовые параметры v1 сохранены.

## Браузерные проверки

Playwright запускает настоящие действия через DOM и указатель, без доступа к скрытому состоянию и без тестовых команд в игровом клиенте. Сценарии находятся в `tests/e2e`:

- Полная партия за каждого героя до результата и реванша.
- Клики по 3D-карте; отмена drag через Escape; повторный успешный drag.
- Пауза и возобновление бота; перезапуск во время незавершённого действия.
- Понятное сообщение при отсутствии WebGL2.
- Ошибка загрузки текстуры, Retry и успешный запуск после восстановления.
- Начальная загрузка при ширине 600 px; подсказка не закрывается через Escape и исчезает при 1024 px. Сужение активной партии 1440 → 600 px останавливает ожидающий ход бота, сохраняя ход, ману, журнал и canvas; расширение до 1440 px продолжает ту же партию.

Все 12 сценариев завершились успешно: четыре полных матча (по два героя в Chromium и WebKit), шесть сценариев взаимодействия и восстановления, две проверки изменения размера окна. Полные партии включают экран результата и запуск новой партии.

Автоматизация использует Chromium 156 и Playwright WebKit 27.2. Проверка установленного Safari 26.6.2 выполнена отдельно вручную: меню, загрузка 3D, замена руки, жетон, призыв, смена хода и возврат после действий бота. В установленном Chrome 155.0.8059.85 проверены меню, замена руки, жетон и направленная способность мага: списание 2 маны, снижение здоровья противника с 30 до 29 и блокировка повторного применения. Автоматический WebKit не отождествляется с установленным Safari.

Сборка `dist` отдельно запущена через `npm run preview`: выбор героя, загрузка ресурсов, подтверждение стартовой руки, первый ход бота и переход к ходу игрока прошли успешно.

Скриншоты меню, колод, замены и игровых партий сохранены в `artifacts/qa`. Основные размеры интерфейса: 1440×900 и 1920×1080.

## Производительность

Стенд `tests/performance` загружает ту же сцену с 14 существами и 10 картами в руке; отдельно включает повторяющиеся массовые эффекты. Он не импортируется производственной сборкой.

Headed Chromium 156, ANGLE Metal, Apple M4 Pro. Retina-проверка: `deviceScaleFactor=2`, фактический DPR сцены ограничен 1.5.

| Размер CSS | Буфер WebGL | Без эффектов, FPS | С эффектами, FPS |
| --- | --- | --- | --- |
| 1440×900 | 2160×1350 | 118.75 | 112.84 |
| 1920×1080 | 2880×1620 | 119.98 | 112.81 |

p95 интервала кадра не выше 9.4 мс; в коротком стресс-прогоне встречались отдельные кадры более 33 мс. Замер подтверждает запас относительно цели 60 FPS на этом Mac, но не является гарантией для любого устройства. Ошибок JavaScript в замере нет. Исходные данные: [Retina](validation/performance-retina.json), [DPR 1](validation/performance-dpr1.json).

Для повторения при запущенном `npm run dev`:

```sh
node tests/performance/measure.mjs --headed --dpr=2 --seconds=12 --out=artifacts/qa/performance
```

## Ограничения версии

Партия не переживает перезагрузку вкладки; сохраняется только настройка звука. Мобильное управление, сервер, мультиплеер, сохранение матча и редактор колод не входят в v1. Полные партии в тестах используют случайную стартовую раздачу, а симуляции ядра — фиксированные seed.
